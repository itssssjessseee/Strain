# Strain

A 12-voice virtual analog synthesizer plugin: VST3, Audio Unit and a standalone app, built with JUCE 9.

## Build on a Mac

You need Xcode (with its command line tools) and CMake 3.22 or newer (`brew install cmake`).

```sh
cmake -B build -G Xcode
cmake --build build --config Release
```

The first configure downloads JUCE, so it needs a network connection. The build makes a universal
binary (Apple silicon and Intel, macOS 11+) and installs it for you:

- `~/Library/Audio/Plug-Ins/VST3/Strain.vst3`
- `~/Library/Audio/Plug-Ins/Components/Strain.component`
- `build/Strain_artefacts/Release/Standalone/Strain.app`

Check the Audio Unit with `auval -v aumu Stn1 Strn`, then rescan plugins in your DAW.

## Build on GitHub instead

Push this folder to a GitHub repository. The workflow in `.github/workflows/build.yml` builds on a
macOS runner, runs `auval`, and attaches `Strain-macOS` (zipped VST3, AU and app) to the run.
Downloaded builds are unsigned, so clear the quarantine flag after copying them into place:

```sh
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Strain.vst3 ~/Library/Audio/Plug-Ins/Components/Strain.component
```

## In the host

- All 135 parameters are automatable and saved with the session.
- Tempo follows the host. The Tempo knob only applies when the host reports none.
- MIDI: notes, velocity, pitch bend (2 semitones), mod wheel, poly and channel aftertouch (the "Slide" mod source).
- The patch browser, Muse and Evolve tools live in the plugin window. "Save" keeps patches in the
  web view's local storage; the session itself always stores the current sound.

## Layout

| Path | What it is |
| --- | --- |
| `Source/Engine.h` | The synthesis engine. Plain C++, no JUCE. |
| `Source/PluginProcessor.*` | Host parameters, MIDI, state. |
| `Source/PluginEditor.*` | Web view editor and the message bridge to the panel. |
| `Source/Params.h`, `Presets.h` | Generated from `tools/params.js`. |
| `ui/index.html` | The panel, embedded in the binary. Generated by `tools/build.js`. |
| `tools/` | Panel sources (`app.js`, `template.html`, `params.js`, `engine.js`) and tests. |

After changing parameters or presets in `tools/params.js`:

```sh
node tools/gen.js Source     # regenerates Params.h and Presets.h
node tools/build.js          # regenerates ui/index.html
```

`engine.js` is the same engine in JavaScript, used when the panel runs in a browser. If you change
the DSP, change it in both `engine.js` and `Engine.h`.

## Tests

```sh
g++ -std=c++17 -O2 -o engine_test tools/engine_test.cpp && ./engine_test   # engine only
cmake -B build -DSTRAIN_BUILD_TESTS=ON && cmake --build build --target StrainSmoke   # plugin glue, headless
```

## Before you share it

- `COMPANY_NAME`, `BUNDLE_ID`, `PLUGIN_MANUFACTURER_CODE` and `PLUGIN_CODE` in `CMakeLists.txt` are placeholders.
  Changing the codes after sessions exist breaks recall in those sessions.
- Builds are not code signed or notarized.
- JUCE is AGPLv3 or commercial. Personal use is fine; distributing a closed-source build needs a JUCE licence.
- Windows is not set up (the editor would also need the WebView2 runtime configured).
